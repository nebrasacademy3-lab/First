NETLIFY + RAILWAY MYSQL CONNECTION
=================================

Use ONE preferred Netlify environment variable:

  MYSQL_PUBLIC_URL = <copy the exact MYSQL_PUBLIC_URL from the Railway MySQL service>

Important:
- The Railway MySQL service must have Public Access / TCP Proxy enabled.
- Do NOT use mysql.railway.internal / *.railway.internal from Netlify.
- In Netlify, make sure the variable scope includes Functions.
- After changing variables, trigger a new production deploy.

Alternative accepted names:
  DATABASE_PUBLIC_URL
  SEARCH_DB_URL

The function also accepts MYSQL_URL / DATABASE_URL only when their hostname is public.
